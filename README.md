# Koscine 3.0

Koscine 3.0 is a clean-room rebuild of the swing-trading decision engine.

This project does not reuse Koscine 2.0 models, predictions, overlays, GO labels,
promotion rules, or reports as implementation inputs. Koscine 2.0 is used only as
a source for the ready daily market data table.

Primary plan: `docs/project_plan.md`
